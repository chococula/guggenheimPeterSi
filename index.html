    Read before first use (certificate)
    
TVs use a self-signed certificate, so the browser must allow it once per TV.
    Open the Allow certificate link in the TV list, choose "Advanced → Proceed", then come back to this page.
    On the first apply, approve the prompt shown on the TV with the remote; the pairing key is then saved in this browser.

    
If the browser asks for "local network access", allow it. Pairing keys and the IP list are stored only in this browser (localStorage) and are never sent anywhere else.
